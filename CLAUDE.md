# Claude Code

Claude Code é o construtor oficial deste projeto. Antes de alterar código, leia o manifesto e o contexto autorizado. Trabalhe em branch, execute todos os testes declarados e não faça push, PR, migration ou deploy sem a aprovação correspondente.

Use `.claude/rules/` somente quando uma regra precisar ser limitada a caminhos específicos; regras compartilhadas permanecem em `AGENTS.md`.
