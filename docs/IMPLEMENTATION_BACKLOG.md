## Critérios de aceite do MVP
1. Nenhum alerta material é somente descritivo.
2. Todo alerta aponta concentração.
3. Todo alerta tem impacto e confiança.
4. Toda recomendação tem 3 alternativas.
5. Toda recomendação tem dono, prazo e KPI.
6. A fila ordena maior impacto/menor esforço.
7. Dados insuficientes bloqueiam certeza indevida.
8. O usuário consegue rastrear a fonte.
