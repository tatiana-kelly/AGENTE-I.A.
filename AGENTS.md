# Instruções para agentes

Leia e siga integralmente [`CLAUDE.md`](CLAUDE.md) antes de alterar este repositório. As regras nele descritas valem para qualquer agente de código, inclusive Codex.

Não mude a divisão oficial de papéis das IAs nem a política estrutural de revisão sem aprovação explícita da Tatiana. Execute `npm test`, `npm run typecheck` e `npm run build` antes de concluir mudanças.
